# 从夯到拉

本地 Obsidian 插件，无需构建或联网。

## 使用

1. 在 Obsidian「设置 → 第三方插件」中刷新列表，启用「从夯到拉」。如列表未刷新，重启 Obsidian。
2. 点击左侧的有序列表图标，或使用命令「从夯到拉：新建分级榜」。填写榜单名称，并选择是否保存到库根目录的「从夯到拉」文件夹（首次使用时自动创建）。不勾选则沿用 Obsidian 默认新笔记位置；插件会记住本次选择。同名榜单自动加序号，已有笔记不会被移动或覆盖。也可用「在当前笔记插入分级榜」命令，直接插入当前笔记。
3. 在阅读视图或实时预览中操作。源码模式显示榜单 JSON；实时预览若显示源码，将光标移到代码块外。
4. 添加条目，拖到分级中；拖到另一条目前可调整顺序。手机上可先点选条目，再点目标分级名称或空白处。
5. 点击分级名称修改名称和颜色。双击条目编辑，右键（触屏长按）可编辑、删除或查看原图。条目不显示按钮、边框和背景。图片填库内路径，如 `附件/封面.png`。名称选填，允许只有图片；名称和图片至少填写一项。
6. 点击「放大榜单」在大窗口中操作，点击「收起榜单」或按 Esc 返回笔记。使用工具栏的「− / ＋」将条目尺寸调整到 75%～200%；缩放仅影响当前显示。
7. 点击「导出图片」打开预览窗口。默认沿用当前榜单宽度，可调整排版宽度（400～2400）后点击「更新预览」。导出实际分辨率为排版宽度的两倍，支持「保存到库」「另存为」，以及环境支持时的「复制图片」。移动端优先使用「保存到库」。
8. 导出按当前榜单样式排版，保留标题与分级色块；移除工具栏、操作按钮、提示文字、选择框、边框和条目背景，PNG 背景透明。预览的棋盘格用于表示透明，不会进入图片。库内图片以内嵌原图参与渲染。超大榜单需减小宽度或拆分。实现使用浏览器 DOM 样式、SVG foreignObject 与 Canvas，无外部依赖。
9. 图片按原图比例完整显示。右键条目选择「查看原图」。原文件本身分辨率较低时，放大无法恢复缺失的细节，建议替换为更高清的原文件。
10. 榜单工具栏不再显示「素材库」按钮。添加或编辑单个条目时，仍可点「从素材库选择图片」，直接填入图片引用，无需手输路径。启用独立「素材库」插件时，选择器会同时展示其主目录和额外素材目录中的图片；选择已有图片不会复制或移动原文件。云端素材先通过素材库插件保存到本地，再从条目图片选择器选取；也可勾选「显示整个笔记库的图片」查找其他图片。
11. 图片选择器的「导入图片」支持批量选取本地文件，新原图保存到独立素材库插件配置的主目录，未启用该插件时使用 `素材库/`。旧版目录仅用于兼容展示已有图片，不再作为新导入位置；同名文件会生成不同名称，避免覆盖。勾选「显示整个笔记库的图片」可使用其他已有图片。支持 PNG、JPG、JPEG、GIF、WebP、AVIF、BMP。删除榜单不会删除素材。
12. 在「设置 → 从夯到拉」、榜单的「⚙ 设置」按钮或命令「从夯到拉：打开设置」中调整榜单目录、默认保存位置、默认缩放、条目宽度、图片高度、完整显示或裁切、条目名称显隐，以及新榜单的分级名称、颜色、数量和顺序。已取消「素材库文件夹」「素材库默认显示所有图片」两项重复设置，图片目录统一在素材库插件中管理。点击「保存设置」生效；「恢复默认值」只填回默认值，需要再保存。显示调整即时作用于已打开榜单，默认分级只影响新建或插入的榜单；路径修改不会移动旧文件。

所有修改直接保存在当前 Markdown 的 `tier-ranking` 代码块中，可用 Obsidian 同步、版本历史和撤销编辑管理。其他设备也需安装此插件才能显示交互榜单。图片引用储存为路径，图片重命名后需手动更新。

## 文件

- `main.js`：可直接运行的插件入口，已内置纯净 PNG 渲染和导出预览，无需加载其他 JavaScript 文件。
- `export-image.js`：保留的导出模块源码，运行时不再加载。
- `styles.css`：浅色、深色及窄屏样式。
- `manifest.json`：插件信息。

版本 1.5.2；支持 Obsidian 1.4.0 及以上。
